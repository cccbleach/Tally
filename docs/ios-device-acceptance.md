# iOS 真机验收清单（Tally 联网版）

> **为什么需要这份清单**：CI 与本地测试只能证明"能编译 + 单元测试通过"。
> 生物识别、小组件、深链、相册选择器、离线队列、Share Sheet 这些**系统交互**只有在真机上才能验证，
> 而且它们的失败模式（权限缺失导致崩溃、小组件空白、离线数据丢失）**CI 完全看不见**。

## 0. 前置条件

- [ ] 真机已连接并在 Xcode 中受信任：`xcodebuild -showdestinations -scheme Tally` 能看到 `platform:iOS, name:<你的设备>`
- [ ] 签名就绪：本机已有证书（OU=XN5LYQCCY2）与描述文件 `iOS Team Provisioning Profile: com.tally.logan`（有效期至 2027-08-30）。
      自检：`./scripts/check-ios-release-assets.sh ios Tally` 应输出"已安装描述文件 1 个（Team: XN5LYQCCY2）"
- [ ] 后端可达：
      - **模拟器**：Debug 默认 `http://localhost:8080`，本地起后端即可（`cd backend && pnpm dev`）
      - **真机**：需把 Debug 的 `TALLY_API_BASE_URL` 指向你 Mac 的局域网 IP（如 `http://192.168.1.5:8080`），
        首次访问会弹**"本地网络"权限**（已在 Info.plist 声明用途）；注意后端 `HOST=0.0.0.0` 且同一 Wi-Fi
- [ ] 需要一个可登录的手机号（短信验证码）；`ALIYUN_SMS_ENABLED=false` 的本地后端会在响应里直接返回 `code`
- [ ] 排查手段：真机日志用 Console.app 过滤进程 `Tally`，或 Xcode → Window → Devices and Simulators → Open Console

## 1. 应用锁（Face ID / 触控 ID）

入口：设置 → **生物锁（Face ID / 触控 ID）** 开关。

- [ ] **开启**：打开开关 → 应弹出系统 Face ID 验证 → 通过后开关保持开启
- [ ] **锁定**：切到后台（上滑回主屏）→ 再切回 Tally → 应看到锁屏盖层（不是登录页）
- [ ] **解锁**：Face ID 通过 → 回到锁屏前的页面
- [ ] **取消验证**：锁屏时点"取消" → **仍留在锁屏**（不得进入 App）
- [ ] **错误面容**：Face ID 失败（可用"使用密码"回退，或遮住面容）→ 仍留在锁屏
- [ ] **关闭**：设置里关闭开关 → 再次切后台回前台 → **不再上锁**
- [ ] **冷启动**：完全杀掉 App → 重新打开 → 因为开关是开启的，应直接进入锁屏

| 失败现象 | 先看什么 |
|---|---|
| **一开启就崩溃** | `ios/Tally/Support/Info.plist` 必须有 `NSFaceIDUsageDescription`（缺失时系统会直接终止进程）。本仓库已声明，若被误删会重现 |
| 开关打不开 | 设备是否设置了面容 ID/密码（`canEvaluatePolicy(.deviceOwnerAuthentication)` 为假时无法开启） |
| 回前台不上锁 | `LockService` 的场景切换订阅；确认开关状态已持久化 |

## 2. 一键记账小组件

入口：主屏长按 → 添加小组件 → Tally → **"记一笔"**。

- [ ] 添加入口显示正常（图标/文案"记一笔 / 3 秒完成记账"）
- [ ] **App 在后台时**点按小组件 → Tally 打开并**直接弹出记账表单**
- [ ] **App 被杀掉时**点按小组件 → 冷启动后同样弹出记账表单
- [ ] **未登录状态**点按 → 先去登录页（**不**弹表单，避免登录页上叠表单）
- [ ] 深链直达：Safari 打开 `tally://add` → 行为与上面一致

| 失败现象 | 先看什么 |
|---|---|
| 小组件列表里找不到 Tally | 扩展是否随 App 一起安装（主屏小组件库搜索 "Tally"）；`TallyWidget` 的 Info.plist 里 `NSExtensionPointIdentifier=com.apple.widgetkit-extension` |
| 点按无反应 | `Tally/Support/DeepLink.swift` 的 scheme 必须与 `CFBundleURLTypes` 里的 `tally` 一致；处理点在 `RootView.onOpenURL` |
| 冷启动不弹表单 | `DeepLink` 是否在 `isAuthenticated` 之后才被消费（未登录会被丢弃，这是刻意行为） |

## 4. 截图识别（OCR 导入）

入口：设置 → **导入账单** → 右上角截图/相册按钮（`PhotosPicker`，筛选截屏）。

- [ ] 选一张**微信/支付宝支付成功页截图** → 出现"正在识别…" → 进入暂存预览
- [ ] 预览里金额、商家、日期、收支方向**正确**（金额优先取页面上的大金额）
- [ ] 逐条可改（账户/分类/跳过）→ 提交后流水出现在列表，且**不重复**
- [ ] 同一张截图**再导入一次** → 被识别为重复并跳过（稳定哈希去重）
- [ ] 选一张**非支付截图**（如桌面截图）→ 给出可读错误（"截图里没有识别到文字…"或"没能识别出金额…"），**不崩溃**
- [ ] 相册里**没有**弹权限申请（`PhotosPicker` 是进程外选择器，这是正常的，不是 bug）

| 失败现象 | 先看什么 |
|---|---|
| 识别为空 | 截图需为**文字版**支付成功页；识别在本机完成，不上传图片（隐私设计） |
| 金额识别错 | `BillScreenshotOCR.extractBill` 的启发式规则（大金额行优先）；把截图留档反馈 |

## 5. 离线写队列（离线记账 → 自动同步）

- [ ] 打开**飞行模式** → 首页应出现离线提示条（"离线模式：…"）
- [ ] 记一笔支出 → 提示变为 **"离线模式：1 笔已记录，联网后自动同步"**，流水列表可见（本地待同步）
- [ ] 再记 2 笔 → 计数变 3
- [ ] 关闭飞行模式 → 回到首页/下拉刷新 → 3 笔**自动同步**，提示条消失
- [ ] 在服务端核对：这 3 笔**只有 3 条**（幂等键 `clientRequestId` 生效，不重复入账）
- [ ] 弱网重试：同步过程中再次断网 → 不丢数据、不重复；恢复后继续
- [ ] 服务端**明确拒绝**的条目（如账户不存在、金额非法）→ 应出队并上报（`Outcome.dropped`），**不得静默丢失**

| 失败现象 | 先看什么 |
|---|---|
| 一直卡在"未同步" | `DataStore` 里的同步触发点（进入前台/刷新时调用 `OfflineTransactionSyncer.sync()`）；后端是否可达 |
| 同步后出现重复流水 | 后端幂等键链路：`POST /transactions` 的 `clientRequestId` + 唯一索引 `uniq_tx_client_request` |

多币种与汇率已下线（迁移 0027 把历史外币金额按汇率折算成人民币，原币种写进流水备注）。

- [ ] 新建账户的表单**没有币种选择器**；金额输入框前缀恒为 `¥`

## 7. CSV 导出

入口：设置 → 导出 CSV（生成后弹 Share Sheet）。

- [ ] 导出 → 分享面板可"存储到文件"/"用 Numbers 打开" → 文件能打开且行数与流水数一致
- [ ] **转义**：找一条备注含 `,` 或 `"` 的流水 → 打开后仍是一条记录、内容完整
- [ ] **公式注入防护**：备注以 `=`、`+`、`-`、`@` 开头时，导出文件里该字段应带 `'` 前缀（Excel/Numbers 不会执行公式）
- [ ] 中文、emoji 不乱码（UTF-8）

## 8. 退出登录 / 退出全部设备

- [ ] 设置 → **退出登录** → 回到登录页；再次打开 App 仍是登录页（本地令牌已清）
- [ ] 服务端核对：该设备的 refresh token 已失效（无法再换取新令牌）
- [ ] 两台设备登录同一账号 → A 设备点 **退出全部设备** → B 设备下次请求应被登出（需重新登录）
- [ ] 退出全部设备时若断网 → 提示"本地已退出，但服务端吊销失败…"（**不得**假装成功）

## 10. 预期行为（避免误判为缺陷）

- 未登录时深链/小组件**不会**直接弹记账表单（先去登录）
- 截图导入**不会**弹相册权限（`PhotosPicker` 设计如此）
- 生产后端会**拒绝启动** `AUTH_MODE=development` / `DISABLE_RATE_LIMIT=true`（安全互锁）
- 生产 /auth/logout 后，access token 在 15 分钟内仍可用（无状态 JWT 的固有语义），但 refresh 已失效
