# Tally 精简版 PRD（MVP）

## 产品定位
一款 **无账号、离线优先、隐私至上** 的原生 iOS 个人记账 App。
目标是让用户「几秒钟记一笔、随时看得懂钱花在哪、数据永远在自己手里」。

## 目标用户画像
- 想养成记账习惯的个人用户（学生、职场新人）
- 重视隐私、不想财务数据上云
- 需要快速、低认知负担的记账体验

## 核心使用场景
1. 在地铁/排队时 5 秒记下一笔午餐支出。
2. 月底查看本月支出结构和趋势。
3. 设置餐饮预算并接收「接近/超支」提示。
4. 换手机前导出 CSV / 完整备份。

## 用户痛点
- 记一笔太慢、要填一堆字段；被迫注册登录；数据被上传；想看旧账和改账很麻烦。

## 差异化价值
- 无账号、无登录、无广告、数据 100% 本地
- 金额、余额、统计口径清晰且经过自动化测试
- 标准 CSV 导出 + 完整 JSON 备份恢复

## 用户故事（MVP）
- 作为新用户，我打开 App 就能直接记账，无需注册。
- 作为记账者，我可以用最少步骤记支出/收入/转账/退款。
- 作为关心开销的用户，我看清本月收入、支出、结余与分类占比。
- 作为会超支的人，我设置预算并看到进度与提醒。
- 作为历史查找者，我搜索、筛选、修改、删除交易；误删可在「最近删除」恢复。
- 作为数据主人，我导出 CSV 或完整备份，也能导入恢复。
- 作为隐私敏感者，我可用面容/触控 ID 锁定 App。

## MVP 功能范围（Must Have）
- 账本管理（默认个人账本，多账本支持）
- 交易：支出/收入/转账/退款，金额/分类/账户/日期/备注/商家；增删改、复制、软删除恢复
- 分类：内置 + 自定义 + 图标颜色 + 启停
- 账户：现金/银行卡/信用卡/电子钱包/储蓄/其他；初始余额；归档；有历史流水时禁止物理删除；转账不入收支
- 首页：本月收入/支出/结余 + 最近交易 + 快速记账
- 交易列表：搜索 + 类型/分类/账户/日期/金额筛选 + 按日分组与日汇总
- 统计：月度汇总、分类占比、每日趋势 + 无障碍文字
- 预算：总预算 + 分类预算 + 进度 + 接近/超支提示
- 数据：SwiftData 本地持久化、CSV 导入导出、完整 JSON 备份恢复、二次确认删除
- 设置：默认币种、每月起始日、外观、生物识别锁、隐私说明、版本

## Should Have（首发后下一版）
- iCloud/CloudKit 同步（可选开启）、周期交易、常用模板、桌面小组件、
  自动备份、地区化繁体/英文、App Shortcuts/Siri、本地通知

## Could Have（再后续）
- Apple Watch、OCR 小票、自然语言记账、AI 总结、共享/家庭账本、资产/负债视图、
  自定义报表、地点/商家识别、iPad/macOS 布局

## Won't Have Now
- 银行自动抓取、读取短信/App 私有数据、股票/基金/加密交易、专业复式记账、
  社交、广告 SDK、未经同意的第三方数据分析、向 AI 服务发送财务明细、伪造银行数据

## 非功能需求
- iOS 17+（本项目面向 iOS 26 SDK 构建，target 17.0）
- 深色模式、Dynamic Type、VoiceOver
- 离线完整可用；冷启动快；大量交易下列表流畅
- 金额一律以最小单位整数（Int64）存储，避免浮点误差
- 不依赖远程服务器；无第三方依赖

## 验收标准（MVP）
1. 无网络、无账号可完成记账
2. 可增删改查交易；支出/收入/转账/退款统计口径正确
3. 修改/删除历史交易后，余额与报表正确更新
4. 可管理账户与分类
5. 可看月度汇总、分类占比、趋势
6. 可设预算并看进度
7. CSV 可重复导入而不产生重复交易；退款关联可往返；完整 JSON 覆盖全部账本，恢复失败不破坏原数据
8. App 重启后交易及关系完整
9. 核心金额计算有自动化测试
10. 深色/大字体/基础 VoiceOver
11. 不依赖远程服务器运行核心功能
12. 指定版本 Xcode 的 Debug、Release、静态分析可通过；关键流程 XCUITest 可通过

## 版本规划
- v0.1 MVP：本仓库（ios-local）实现
- v0.2：Should Have 列表
- v0.3：Could Have 中优先级高的（Watch、Siri）

## 收费模式建议
- MVP 免费。后续可「买断制 + iCloud 同步/高级报表为内购（StoreKit 2）」，
  或无广告 + 买断；不建议订阅压制轻度用户。最终以用户确认为准。
